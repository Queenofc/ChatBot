🧠 MindFlow – Your AI Companion for Focus & Creativity
MindFlow is an AI-powered chatbot designed to enhance focus, boost creativity, and assist users in problem-solving. Built with React, Node.js, and MongoDB, and powered by Gemini Flash 1.5, it processes both text and image inputs, generating insightful responses and visual outputs to enrich user interactions.

✨ Features

1)Engage in intelligent discussions tailored to your needs.

2)Text & Image Processing – Accepts both text and image inputs, returning relevant responses or enhanced visuals.

3)Creativity Booster – Generates writing prompts, brainstorming ideas, and AI-assisted content.

4)Focus Enhancement – Provides structured guidance to maintain deep work and productivity.

5)Problem-Solving Assistant – Breaks down challenges and suggests solutions.

6)Personalized Experience – Adapts to user preferences for a customized AI experience.

7)Data Persistence – Stores chat history, images, and user preferences in MongoDB.

8)Seamless UI – Clean and intuitive design for smooth interactions.

🛠 Tech Stack

AI Model: Gemini Flash 1.5

Frontend: React

Backend: Node.js

Database: MongoDB
